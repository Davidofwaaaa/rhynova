# Rhynova

Swiss cross grid. A 3×3 module: the plus is the center cell plus north, south, east, and west. The four corners stay empty.

Open `index.html`. Single / focal draws one centered cross. Repeating field tiles that module on a pitch of 3 cells. Density is the cell size in pixels, with column and row counts and 1:1, 4:5, 16:9, or custom aspect. Random squares follow a seed and a fill percent. PNG export is transparent when the background is off. SVG export is rectangles.

Reference frames live in `references/`.
